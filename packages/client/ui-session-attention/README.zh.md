# @deepseek-ai/dsh-client-ui-session-attention

[English](README.md) | 中文

Web GUI 会话等待提醒覆盖插件：浏览器半边向 root 作用域的 `shell.overlay` 列表槽（由 `dsh-client-ui-layout` 拥有并声明）贡献一个条目。该条目订阅标准 `useSessions` 数据流——与侧边栏状态点同源——在任一会话等待用户操作时持续渲染一个 3D 动画面板：待处理的交互（审批 / 计划审阅 / 提问）或后台会话的 AI 回复已完成而用户尚未打开。Host 半边为空；本插件是纯展示，不持有任何 Host 端行为。

面板在有待办期间持续可见，而不是收成一个需用户再次点开的徽章；它固定悬浮在浏览器视口的右上角，随页面一起覆盖在最上层。每个提醒行带有该会话的状态色与本地化种类标签，点击行即在侧边栏打开该会话以便用户处理。有待办时浏览器标签页标题会加 `(N)` 前缀，使提醒在标签页切到后台时仍可见。所有等待会话处理完、所有后台回复都被打开后，覆盖层整体消失。标签页切到后台时 3D 动画暂停帧循环，回到前台时从同一时间点恢复，不额外消耗资源。

3D 动画是一个绘制在 Canvas2D 上的小型行星系，采用手写透视投影与深度排序：一层发光粒子围绕呼吸的中心辉光做 3D 旋转，外侧一条倾斜轨道环上有一颗带渐隐拖尾的亮彗星，每个粒子按自身相位闪烁。它是一个真正的 3D 效果（粒子在球面上、做 3D 旋转、再透视投影到 2D），保持零依赖、可在 jsdom 中完整测试——投影数学是纯函数，画布绘制由该纯帧计算驱动。所有可绘制元素都以加法混合（`lighter`）重复贴同一张预渲染的径向渐变光晕精灵，重叠粒子积累的是亮度而非不透明度；每帧清空完整设备像素位图，`devicePixelRatio > 1` 的屏幕不会残留上一帧的像素。本包有意不依赖 three.js 库：WebGL 渲染路径在逐文件 100% 覆盖率门禁下不可达（jsdom 无 WebGL 上下文），且动态原型里运行时 CDN `<script>` 加载是一条不适合已发布插件的网络依赖。主色跟随当前最高优先级提醒种类：琥珀（审批）、紫（计划审阅）、青（提问）或绿（回复完成）；当面板每行都是后台完成时使用绿色主题。

提醒种类与侧边栏状态点完全对应：`pendingInteraction`（`approval` / `plan-review` / `question`）是琥珀色“等待用户”点，`completed` 的后台会话（跑完且当前未选中、尚未打开过）是绿色“已完成”提醒点。当前打开的会话不会作为完成项出现——它的回复完成就在视野内，不是提醒。同一会话若有待处理交互则优先于完成。行按种类优先级（等待在前）再按会话 id 排序，至多渲染五行，其后跟一条“还有 N 个会话在等待…”的尾巴。

## Model Experience

无。覆盖层渲染既有浏览器会话列表；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## Known Limitations and Deferred Work

- **动画是 Canvas2D 而非 three.js 库**——WebGL/Three.js 渲染路径在逐文件 100% 覆盖率门禁下不可达（jsdom 无 WebGL 上下文），因此包内改用手写 3D 投影。它是真正的 3D 效果，但视觉上比带着色的 three.js 场景更简朴。
- **无 locale 命名空间**——文案走注入的中文默认值而非标准本地化席位，因此切换语言不会重译面板。若面板需要翻译，接入 `dsh-client-locale` 是一项后续本地化工作。
